# 👾 Portfolio • Isabela Wisses

Portfólio desenvolvido para apresentar minha trajetória, habilidades e projetos na área de tecnologia, com foco em uma interface moderna, responsiva e com identidade visual mais tecnológica.

---

## 👩🏻‍💻 Sobre

Sou **Isabela Wisses de Figueiredo**, técnica em Desenvolvimento de Sistemas pelo **SENAI**, com interesse em desenvolvimento web, lógica de programação e criação de projetos práticos.

Este portfólio foi criado para reunir minhas principais informações profissionais de forma clara, visual e organizada.

---

## 🎯 Objetivo

O objetivo deste projeto é construir uma presença digital profissional, reunindo:

- apresentação pessoal
- habilidades técnicas
- formação
- projetos desenvolvidos
- formas de contato

---

## 🛠️ Tecnologias utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
- **Google Fonts**
- Estrutura responsiva e navegação suave

---

## 📂 Seções do portfólio

- **Home**
- **About**
- **Projects**
- **Skills**
- **Formação**
- **Contact**

---

## 💡 Destaques do projeto

- Interface moderna com identidade visual tecnológica  
- Estilo visual com tons escuros, roxos e brilho suave  
- Layout responsivo para diferentes dispositivos  
- Navegação fluida entre seções  
- Estrutura organizada e limpa  
- Apresentação visual dos projetos e habilidades
